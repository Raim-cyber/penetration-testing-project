# Penetration Testing Project

University penetration testing project demonstrating practical cybersecurity skills including reconnaissance, vulnerability scanning, exploitation, and web application testing.

## Tools Used
- Kali Linux
- Nmap
- Metasploit
- Hydra
- sqlmap
- DVWA
- Burp Suite

## Topics Covered
- Vulnerability Assessment
- SQL Injection
- Reflected XSS
- Enumeration
- Exploitation
- Web Security Testing

## Disclaimer
This project was conducted in an authorized academic lab environment for educational purposes only.
